# 클로드 앱에 바로 올리는 스킬

클로드(claude.ai · 데스크톱 앱)의 **사용자 지정 → 스킬 → 추가 → 스킬 업로드** 에 그대로 올리면 되는 압축 파일입니다.

## humanize-korean (AI 티 없애기)

AI가 쓴 한국어 글에서 「AI 티」를 걷어내고, **내용은 그대로 둔 채 말투만** 고쳐 주는 스킬입니다.

- 받기: 오른쪽 **Releases** 에서 `humanize-korean_claude-app.zip` 을 받습니다. **압축을 풀지 말고** 그대로 올리세요.
- 부르기: 새 대화에 글을 붙이고 「AI 티 좀 빼줘」 — 또는 입력창에 `/` → `humanize-korean`
- 앱에서는 채점 도구 일부가 돌지 않을 수 있어 답 맨 위에 안내 한 줄이 붙을 때가 있습니다. 오류가 아니며 고치는 일은 그대로 합니다.
